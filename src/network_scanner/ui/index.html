Using IP Scanner

Keep this guidance open while reviewing or running a scan.

Run a network scan

  1. Select Scan detected network to use the active adapter and subnet.
  2. Use Scan custom range only when you know the starting and ending IPv4 addresses.
  3. Wait for the scan to finish before starting another scan.
  4. Review the new entry under Previous network scans.

Remember: Scan only networks that you own or are authorized to assess.

Understand the indicators

  • G identifies the detected default gateway.
  • W identifies an HTTP or HTTPS service.
  • P identifies a device that answered the ICMP ping check.
  • Evidence shows whether ICMP, TCP, or ARP established the device's presence.
  • High confidence uses a discovery protocol or multiple active signals.
  • Medium confidence uses one active response. Observed is ARP-only evidence.
  • Broadcast addresses and proxy-ARP-only entries are attempted but excluded from device totals.
  • U, B, and 6 are reserved for UPnP, Bonjour, and IPv6 discovery.

Data and privacy

  • Scan history is stored locally on this computer.
  • The interface is served only on the local loopback address.
  • Clearing history removes the saved scan records from this installation.

Resolve common issues

  • No adapter detected: Confirm that Wi-Fi or Ethernet is connected.
  • No devices found: Confirm that the requested range is on the locally connected network. Client isolation can prevent local discovery.
  • Page does not respond: Confirm that the IP Scanner service is still running.
